# Saved shield V2 ticket anatomy

The completed shield V2 passed accounting but failed net financial gates.
Earlier joint-tail and return-cost diagnoses already described fixed-ticket
shares and mean notionals. This separate question links the retained V2 units,
actual delayed opens and issued instructions to each existing model ticket.
It does not rerun or retune an allocator, account, rebalance solver or BT.

The ticket-inspection Module has one saved-step Interface at the execution
evidence Seam. Actual retained-trace/book and synthetic-memory Adapters supply
the same numeric inputs. Its Implementation reconciles quantities, cash, NAV,
paid costs, turnover and exact original strict USD1e-6 ticket counts before
emitting descriptive rows. Original admitted market/RF delivery is unchanged.

Each formal book day remains, including first capital deployment, no-fill
days, zero-ticket scheduled fills and terminal unfilled requests. Use actual
retained units, not an assumed nominal holding. Actual signed notional is the
unit change times the admitted execution open.

For the same saved target and actual book, prefee target gap plus
minus target weight times the actual paid fee must reconcile to executed
dollars within original USD1e-6 money coherence. A prefee gap inside the
original noop threshold followed by a charged ticket is a fee-base crossing
label. It is an arithmetic observation, not a fee-free funded counterfactual
or a causal attribution of wealth, performance or all commissions.

Notional buckets are fixed before new labels: original strict-threshold
tickets below USD1, USD1 to below10, USD10 to below100, and USD100 plus.
These are fixed multiples of the original USD1 model commission, not a new
trade threshold or turnover cap. Subthreshold unticketed unit movement is
retained separately; proportional dollar notional is not silently discarded.

Filled-instruction provenance compares the previous **issued** instruction:
initial deployment, an identical issued target, a changed target with the
same nominal but changed saved risk fraction, or a changed nominal/target.
Monthly refresh dates, numerical value changes, requests and actual fills
remain distinct. Categories are partitions, not isolated causal effects.

Freeze inputs, definitions, code and successful synthetic checks before new
real ticket labels. Independently validate all 7,532 original return dates,
the canonical RF, every original ticket/paid-fee total and twenty saved-record
prefixes. Keep monetary/target tolerances and every prior failure unchanged.
No new CAGR, Sharpe, drawdown, qualification, target or capital account exists.
Exposed overlapping histories are not independent samples or forward proof.
