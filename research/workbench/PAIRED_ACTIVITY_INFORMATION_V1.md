# Paired activity information ablation v1

This is one exposed-history consumer-level information ablation, not a new
economic factor, an automatic ninth representative, or a rescue of the rejected
HMM substitution. The original seven/eight rosters and every original result
remain unchanged. Both archived complete source policies remain financially
rejected independently of their technical eligibility.

## Frozen question and controls

Two study-specific eight-expert pools replace only the original defensive-style
role. One uses `two_segment_core_price_momentum_control_v1`; the other uses
`two_segment_core_activity_momentum_v1`. The other seven identities, including
GARCH, their order, and all original causal accounting remain identical.
The siblings never coexist in one pool or count as independent risk sources.
The shared study-role group is a documented coarse classification; it does not
rewrite the original activity eligibility record or native source policy.

The paired sources have the same complete dollar/options stock-gold-BIL parent,
same style budget, noncore targets, original 35/30/20/15 rank shares, 126-session
lookback, 21-session skip, and 105 past log returns. Only uniform-time versus
reported raw-close-times-share-volume return weighting differs. That activity
proxy is not actual traded dollars, fund flows, outstanding-share turnover,
constituent trading, stock-level PIT, or an independently identified economic risk.
All source scope, vintage, age, original information clocks, and refusals hold.

Each source is paired with equal eighths and the exact existing rolling pair law:
126 matured NET/RF observations, 84 chronological training and 42 validation,
all 28 pairs, original ERC/net-score/switch proxy, twelve-decimal comparison keys,
and explicit non-successful equal state while immature. No source model, rank,
target, shadow, account, independent BT, or benchmark pipeline is rerun.
The existing monthly Adapter preserves native recommendations and initialization;
no new RF/target/assessment view or Adapter is created. The price control has its
own frozen cached technical prerequisite before financial registration.

## Module, Interface and evidence

`paired_activity_information_v1` accepts the two fixed complete-policy pools,
calendar and original asset coordinates. It reuses the actual original pair and
composition functions in isolated namespaces. The two learning states never
cross. Its Adapter reuses the existing independent all-pair scalar oracle, retains
both source/decision streams with untruncated binary64 values, verifies prefixes,
and uses the original unified-target main-account implementation.

All four real cohort identities must register before any new meta score/target.
Every exact packet, source/code/policy dependency and all four registrations must
be remotely published and verified before the first account. Four configurations
and sixteen full paths are declared; this is not a user-wide research quota.
Every original date, fresh USD10000, initial DD peak, RF, base/stress cost,
USD1 tickets, one/two-session delay, cash funding, 1x limit, actual-holdings
2.5pp band, SPY/QQQ and extra original gate is unchanged.

Cached source NET/RF shadow books remain assessment references, not combined
capital. Each main path uses one unified underlying-asset target and its own
actual holdings, cash, orders and fees. No summing source USD10000 books,
averaging source CAGR/DD, or transferring a gross-wealth guarantee to net capital.
Idle cash still earns zero; BIL remains an ETF, not risk-free account interest.

## Interpretation fixed before outcomes

Report activity-minus-price for CAGR, RF Sharpe, DD, turnover, model tickets and
fees on every path within each meta law. Qualification still requires one whole
rule to pass all original gates on all four paths. Publish every outcome and
failure; no metric splicing or automatic winner promotion.

The comparison to the old defensive expert is not an isolated activity effect:
its parent policy and assets also differ. Only the matched sibling contrast is
the field ablation. Existing source results, the 109/128 differing archived
opinions, and 243 earlier completed financial configurations are exposed.
Pool selection is adaptive; neither rolling scores nor these comparisons are
independent OOS/forward proof, causal economic identification, or main-DD guarantees.
