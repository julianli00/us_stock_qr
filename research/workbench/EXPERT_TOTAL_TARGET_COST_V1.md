This study changes a cost reference, not the four complete experts, original
NET-RF risk estimates, coefficients, windows or financial acceptance. It is
not a correction to a frozen old policy: incremental expert-switch cost and

## Frozen cost geometry

The original six-pair rule compares candidate fractions with the preceding
expert fractions, both evaluated on today's source opinions. That is an
incremental manager switch under a current-opinion counterfactual. It can
be zero when the source opinions themselves moved since the previous origin.

The new rule compares each candidate's current unified target with the
previous origin's final desired meta target. Carry that vector through every
initial/month-end decision, including unscored equal quarters. It is not
actual holdings, actual NAV, the last issued request or a filled position.
Do not silently replace a missing post-initial vector with cash or current
equal opinions.

Use the unchanged5bps/side plusUSD1per changed coordinate on reference
USD10000,changed-coordinate tolerance1e-12,amortized over21sessions.
The source NET histories already contain historical source-policy fees.
Adding a total future desired-target cost proxy can charge overlapping
economic movements; it is not guaranteed exact incremental main cost,
an unbiased NET forecast or a no-double-charge decomposition.

Keep all six trained pair alternatives,84session equal-risk fractions,
42session validation,weaker NET-RF score,12decimal lexical keys and two
selected experts. No return-sign participation cutoff,variance model,
window,coefficient,holding band or pool membership is tuned.
Keep seven initial unscored quarters and all121original decisions.

The small real Module separates cost assessment of two desired targets from
source opinion observation. Reuse unchanged source risk/maturity/ERC
calculations; only the declared nominal reference and its carried state
change. Synthetic and saved Adapters cross this Interface. Retain all
unrounded source observations,old same-origin cost references,new costs,
all pair scores and state before each computation. Independent scalar
cost/weight/score checks and five exact prefixes must pass.
