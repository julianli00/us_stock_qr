# Lagged SPY price-impact participation expert V1

Prepare one complete monthly core-versus-actual-BIL policy for a possible
market-liquidity stress role in an expert pool. This is neither a new direct-stock
factor family nor a single-champion improvement loop. No actual source opinion,
financial run, technical admission, pool membership or qualification is claimed.

For each completed month-endD, read only SPY inputs endingD-1. Each daily
measurement is absolute adjusted simple return per reported closing-valuation
activity, using saved reported raw close times reported share volume.
Compare the latest21measurements with the immediately preceding nonoverlapping
252-measurement mean. Round their ratio to12decimals; a value strictly above1
requests98%actualBIL. Otherwise request an equal six-style core totaling98%.
Retain2%idle cash and every original execution/funding/financial gate.
The first opinion requires274prior adjusted price levels: position274in the
full source lattice, with the current decision bar numerically excluded.
Zero reference activity-adjusted return is a fatal undefined comparison, not
neutral data, zero-cost success or a safe BIL fallback.

Amihud2002, *Illiquidity and stock returns: cross-section and time-series effects*,
DOI10.1016/S1386-4181(01)00024-6 motivates return-per-activity measurement only.
The first ordinary Crossref bibliographic response was retained separately.
This ETF proxy, information lag and month-versus-year participation rule are
not the paper's stock-level replication or an imported empirical result.
Reported close times volume is not executed dollars, flow, share turnover,
bid-ask spread, market depth, true impact or this model's actual transaction cost.
Volatility, ETF structure, distributions, actions and reporting units can confound
it. No risk independence, protection, low turnover or return gain is established.

The old activity-momentum experiment weights signed individual-fund returns
by activity and changes within-core ranks on a parent strategy. This new
absolute broad-market return-per-activity state instead chooses complete
participation; it does not replay that policy or retune an old volatility bound.
Only original admitted fourteen-asset OHLCV/RF is read. No quote, alternate
adjustment, RF view, source-gap fill or universe expansion is introduced.
The one-session lag is declared information use, not proof of every historical
first publication, revision-free PIT or full fund methodology continuity.

## Module and Interface

`price_impact_state` validates the exact measurement window and returns
reproducible state; `decision` requires a genuine covered month end and complete
lagged history. `build_targets` preserves every market date, sparse native
opinions, full binary64input records before resolution and explicit warmup.
It accepts the existing `MarketData` Interface because this mechanism needs
both price and reported volume, not closes alone. At `StrategyExpert.observe`,
the existing monthly Adapter still separates opinion availability from
0/125/126NET maturity. No empty platform or patched old namespace is needed.

Preparation performs synthetic checks and read-only input-quality readiness,
not actual historical indicator calculation. A separate frozen financial
program and actual registration/publication must precede every real opinion,
original four-path account and independent accounting proof. Later source
admission and deliberate pool inclusion are separate decisions. All264exposed
prior completions, failures, source stops and one-day forward identities remain;
historical availability is counterfactual, not independent prospective proof.
No orders or live deployment.
