# Retained expert opinion geometry diagnosis V1

This is a new descriptive read-only diagnosis of current policy opinions in
the closed original-eight-plus-price-impact study. It is not another L1-medoid
consensus rule, instrument-concentration strategy, next-month covariance
calibration, fee forecast audit or financial evaluation.

The question is how many distinct current underlying-asset opinions and
affine exposure directions exist, and when the saved rolling selected pair
contains equal current opinions. Every retained decision is included,
including unscored initial states. Source return values and future financial
outcomes are not diagnostic labels; no score or allocation is recomputed.

The pure `inspect_opinions` Module accepts already known complete funded
opinions and an optional saved selected pair. The retained-record Adapter
checks identities, known-at dates, asset order, input/resolved consistency,
unscored state and the complete original pair menu without calling the scorer.
Exact binary64 equality treats signed zeros equally.
The source's explicit14-asset order is pinned; an older12-asset constant is
not a replacement universe or a reason to crop coordinates.

All current opinion pairs retain asset-target L1 distance and normalized
minimum-coordinate overlap. Independent rational scalar arithmetic checks
these calculations. Neither quantity is actual executed turnover or fees.
Same-date first-eight versus all-nine comparisons describe the opinion set,
not replayed original-eight financial controls.

Exact rational affine rank and numerical centered-SVD rank are reported
separately. A common per-date threshold applies to both opinion sets:
the larger of1e-12 and max(rows,columns) times binary64epsilon times the full
centered largest singular value. The floor is a frozen diagnostic resolution,
not a new economic acceptance threshold or an optimized parameter.
Raw singular values and exact ranks retain rounding sensitivity. No regularizer,
solver scan, tolerance change or default follows a failed check.

Equal current opinions do not make complete experts identical or invalid.
Linear dimensions and coordinate overlap do not establish independent economic
risks, future diversification, causal alpha, calibrated probabilities or
portfolio qualification. No source is selected, excluded or promoted here.

Criteria/code and synthetic checks freeze before actual geometry calculations.
New private input records retain exact source float.hex operands before each
calculation; resolved records follow. Raw opinions and dated source rows stay
private on the SSD; public output contains only aggregate descriptive evidence.
All source models, targets, shadows, accounts, benchmarks, financial failures,
267completed configurations and zero qualifiers remain unchanged.
