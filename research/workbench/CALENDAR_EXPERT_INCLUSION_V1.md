# Controlled calendar expert inclusion V1

This study deliberately appends the already technically admitted complete
calendar policy to the original eight representatives. It does not add the
credit or macro alternatives, reopen rejected sources or change global rosters.
The calendar policy's four standalone financial rejections remain unchanged.

The complementary hypothesis concerns a predetermined annual equity/BIL
participation opinion, rather than recent returns, price trend, covariance or
credit forecasts. The same underlying equity assets and exposed historical
design do not create nine independent risk sources. All 256 earlier completions
and the calendar's standalone failure are known; this is not independent OOS
or prospective evidence.

## Module and source Interface

`calendar_program_expert_v1.load_calendar_expert` is the versioned read-only
constructor for this source's schema 3 published program. It checks actual
registration/publication/completion events, the deferred native target proof,
all four original funded receipts, technical admission, exact common RF and
the already completed ten-year base NET book. It exposes the existing
`StrategyExpert.observe` Interface through `ArchivedMonthlyExpert`.

The original static-packet loader continues to provide the other eight dense
and monthly Adapters without modification. No source generator, quote request,
new shadow account, RF view, historical introduction or old control is replayed.
Calendar opinion availability is not mature NET assessment history.

## Fixed cohort

Register two new identities: equal ninths and the unchanged original
126/84/42-session rolling pair rule, k2, training ERC, weaker training/validation
NET score, original nominal switch proxy, 21-session amortization and
12-decimal lexical tie rule. Retain all 36 candidate pairs at mature decisions.
Short initial NET history uses explicitly unscored equal ninths, not a filled
successful score or an omitted source.

Freeze the pool, unchanged law, code, inputs and checks before new combination
outcomes. Both actual registrations must precede new target derivation, and
both complete-cohort packets plus their code must actually publish before any
new funded account. Existing eight-expert equal and rolling books are matched
cached controls, not additional trials.

Each candidate retains one unified underlying-asset target and one fresh
USD10000 main account on every original full ten/five-year base/stress path.
Original RF, initial peak, cash funding, costs, delayed open, actual monthly
holding band, independent BT and every financial gate remain. No averaging
CAGR/drawdown, capitalized shadow sums, parameter sweep or passing-path splice.

Technical admission permits this explicit controlled test; it does not predict
financial success or automatically promote the new expert into a live portfolio.
