# Published calendar policy financial program V1

This program continues the already frozen calendar source policy. It does not
change its months, six equity families, BIL state, information clock, target
budget or original execution terms.

## Publication and source chronology

The registration packet freezes executable decisions, source identities and
synthetic readiness. It is schema 3 and explicitly has no historical target
derivation proof at registration. Registration and actual remote publication
must both precede the first real native calendar target and funded account.
After the real publication fence, the program constructs the complete native
month-end history once and retains each input before its resolved opinion.
Missing or partial source preparation is preserved, never silently replayed.

The existing `ArchivedOpinionPolicy` Adapter presents these native opinions at
the existing `DecisionPolicy.decide(CapitalSnapshot)` Seam. The existing
`CloseMarkedPairPolicy` is a materially different rolling-expert Adapter at that
same Seam; it is not executed again as a new control.

Each formal path begins with its own USD10000, zero units, cash and initial
drawdown peak. Its real preceding-session anchor uses only the already known
native month-end opinion, not a backdated ordinary signal. Later decisions use
the original monthly actual-holding 2.5 percentage-point band. One unified
fourteen-asset target is funded at the original one/two-session delayed open,
with 5/20 bps per side and USD1 model-ticket commissions. BIL is a traded ETF;
idle cash does not receive synthetic interest.

Gross exposure retains the original sum-of-observed-asset-weights reporting
convention. The reused generic executor's ratio of total asset value to NAV is
mathematically equivalent but can differ in binary64 summation. The new program
retains the original reported quantity without changing money, source targets,
fees, execution, test tolerances or the old frozen executor.

## Independent evidence

An independent signal-month table checks all source targets and their
chronological records. Prefix truncations and price perturbations check the
calendar opinion without fitting returns. Actual main close values, cash,
decision targets, holding gaps and execution delays are independently checked.
The independent BT book and scalar metrics audit every original formal return.
Five fixed real main-book prefixes are auxiliary causality audits, not additional
economic rules or independent financial trials.

Only the complete original ten/five-year base/stress paths can support a review.
All original RF, fresh capital/peak, Sharpe, net CAGR, drawdown, tradable SPY/QQQ
and extra benchmark gates remain. Turnover, modeled tickets and fees are reported.
No historical benchmark, old source policy or completed account is replayed.

After complete funded evidence, a separate source-expert technical review checks
the published program, native targets, exact common RF, source chronology and
the actual reference NET book through `StrategyExpert.observe`. Financial
rejection alone does not exclude a technically valid expert. Technical
admission still does not automatically add it to any expert pool.

## Limitations

This is one complementary calendar policy, not a standalone-champion search or
an independent risk source. Its mechanism and the 255 earlier completions are
exposed history. Publication, correct bookkeeping and prefix causality are not
independent out-of-sample or prospective alpha evidence.

The new financial freeze explicitly starts from J922 and 255 completions. It
reuses the old market contract only and does not inherit the old residual
completion count 228. Frozen preparation, old failed preflights, source refusals
and prior financial results remain unchanged.
